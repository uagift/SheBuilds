# 👩🏽‍💻 SheBuilds Rwanda

> **Learn. Build. Grow.**

SheBuilds Rwanda is a responsive and accessible registration experience designed for a fictional girls-in-technology community in Rwanda.

The project focuses on making registration simple, supportive, and engaging through real-time validation and encouraging feedback.

## ✨ Features

* 📝 Real-time form validation
* 📧 Email and Rwandan phone number validation
* 🔐 Password strength meter with live checklist
* 👁️ Password visibility toggle
* ⚠️ Clear error and success feedback
* ♿ Accessibility-focused form design
* 📱 Fully responsive layout
* 🎉 Animated registration success state
* ⌨️ Keyboard-friendly navigation

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Responsive Design
* Accessibility (ARIA)
